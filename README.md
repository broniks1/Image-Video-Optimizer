## ⚡ О проекте

Это **веб-версия** оптимизатора изображений, написанная на Python (PyScript + Pillow) и работающая полностью в браузере. Никаких серверов, никакой установки — просто откройте ссылку и пользуйтесь.

---

## ✅ Что умеет веб-версия

- 🖼 **Сжатие изображений** (JPG, PNG, WEBP, BMP, GIF)
- 🎚 **Настройка качества** (10–100%)
- 📐 **Изменение размера** (до 1920 / 1600 / 1280 / 1024 / 800 px)
- 📦 **Пакетная обработка** — сразу несколько файлов
- 🌐 **Русский / English** интерфейс
- 🔒 **Файлы не покидают ваш компьютер** — всё обрабатывается локально в браузере

---

## ⚠️ Ограничения веб-версии

Веб-версия работает на **PyScript / Pyodide**, и это накладывает технические ограничения:

- ❌ **Сжатие видео недоступно.** FFmpeg невозможно запустить внутри браузера — это ограничение технологии, а не желание разработчика.
- ⏳ **Первый запуск занимает 10–20 секунд** — браузер подгружает Python-движок (~15 МБ).
